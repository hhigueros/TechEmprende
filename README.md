# TechEmprende - Landing Page para Emprendedores Tecnológicos

Landing page desarrollada como proyecto de Frontend y posteriormente migrada a un entorno profesional utilizando Git, GitHub, TypeScript y Programación Orientada a Objetos (POO).

## Requerimientos

### Requerimientos funcionales

* Mostrar información sobre emprendimiento tecnológico.
* Permitir la navegación entre las diferentes secciones del sitio.
* Mostrar y ocultar el menú de navegación en dispositivos móviles.
* Presentar las distintas áreas tecnológicas disponibles.
* Mostrar información para formalizar un negocio tecnológico.
* Presentar recomendaciones para vender servicios tecnológicos.

### Requerimientos no funcionales

* La página debe ser amigable e intuitiva.
* Debe funcionar correctamente en diferentes dispositivos.
* El código debe migrarse a TypeScript.
* La lógica debe organizarse utilizando Programación Orientada a Objetos.
* El proyecto debe administrarse mediante Git y GitHub.

## Estructura del sitio

* Hero principal
* Áreas tecnológicas
* Formalización del emprendimiento
* Cómo vender servicios tecnológicos
* Contacto (Footer)

## Tecnologías

* HTML5
* CSS3 (SASS)
* JavaScript
* TypeScript
* Git y GitHub
* Programación Orientada a Objetos

## Cómo ejecutar

1. Clonar el repositorio.
2. Instalar las dependencias con `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir la dirección local indicada por Vite.
